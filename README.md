# VGN Project Page

Project page for **VGN: Value-Guided Navigation from RGB for Robot Motion Planning**.

This website intentionally follows the clean academic structure of the
[Nerfies project page](https://nerfies.github.io/) and adapts its project-page template
for VGN.

## Local preview

```bash
git clone https://github.com/Masrur02/VGN-ProjectPage.git
cd VGN-ProjectPage
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Media

The committed MP4 files are lightweight preview encodes so that the repository remains small.
For a final public release, replace them with higher-quality web encodes using the same filenames,
or replace the full-video block with a YouTube embed.
