Abstract

Visual navigation from monocular RGB requires reliable scene understanding and safe goal-directed decision making. VGN learns a dense traversability map and a goal-conditioned cost-to-go (CTG) representation directly from a single RGB observation. A teacher pipeline combines vision foundation models with classical planning to convert static RGB images into dense navigation-oriented pseudo-supervision.

At deployment, the teacher is removed. The student predicts traversability and CTG from RGB, providing a reusable planning interface that supports graph search, direct gradient rollout, and gradient-guided sampling. This decouples representation learning from a specific trajectory decoder and enables closed-loop navigation in simulation and on a Unitree Go2.

From RGB to a planning representation

During training, the teacher converts grounded semantic regions into traversability supervision and propagates a goal-conditioned CTG field using classical planning. The student learns these dense representations directly from RGB.

Semantic Traversability

Semantic region supervision distills terrain-aware information into the student’s dense representation.

Teacher semantics → dense student features → traversability

Goal-Conditioned CTG

The CTG field changes with the projected goal while respecting traversability-aware scene structure.

Traversability + goal + spatial context → dense CTG

Planner-Agnostic Navigation

VGN does not directly regress one fixed trajectory. The same learned traversability + CTG representation can be consumed by multiple downstream planners, including graph search, direct gradient rollout, and gradient-guided sampling.

Runtime

The learned VGN pipeline runs in 42.7 ms on RTX 4090 (23.44 FPS), compared with 473.8 ms for the teacher pipeline. On the Unitree Go2 deployment stack, RGB-to-local-motion planning runs at approximately 1.40 Hz.
