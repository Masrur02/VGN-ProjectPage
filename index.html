Abstract

Visual navigation from monocular RGB requires reliable scene understanding and safe goal-directed decision making. VGN learns a dense traversability map and a goal-conditioned cost-to-go (CTG) representation directly from a single RGB observation. Instead of relying only on expert trajectories or robot interaction, a teacher pipeline combines vision foundation models with classical planning to convert static RGB images into dense navigation-oriented pseudo-supervision.

At deployment, the teacher is removed. The student predicts traversability and CTG from RGB, providing an explicit planning representation that can be consumed by graph search, direct gradient rollout, or gradient-guided sampling. This decouples representation learning from a particular trajectory decoder and supports closed-loop navigation in simulation and on a real Unitree Go2.

Method

Learning dense planning representations from static RGB

The training pipeline uses text-grounded semantic regions to derive dense traversability supervision. A sampled image-space goal is then used to propagate a traversability-aware CTG field with classical planning. The student learns both representations from RGB and keeps only the lightweight inference path at deployment.

Semantic distillation

Dense student features are aligned with teacher semantic-region embeddings so that the learned traversability representation retains terrain-aware semantic structure.

Semantic distillationTeacher region semantics → dense student features

Goal-conditioned CTG

The CTG head combines traversability, the projected goal, and spatial context to predict a dense value field that changes with both scene geometry and the destination.

Goal-conditioned CTG headTraversability + goal + spatial context → dense CTG

One representation, multiple planners

VGN is planner-agnostic by design: it does not directly output a single fixed trajectory. The same learned traversability + CTG representation supports graph search, direct CTG-gradient rollout, and gradient-guided sampling. This makes the representation reusable as a planning interface rather than coupling learning to one planner architecture.

Real-World Deployment

VGN is deployed closed-loop on a Unitree Go2 using monocular RGB, with the learned representation driving local image-space planning across outdoor trails, obstacle-rich scenes, indoor corridors, and illumination changes.
